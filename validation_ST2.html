Reflection on the Validation Process

Errors encountered: The AIS page initially had a duplicate id attribute on the impact summary panel (from copying a section structure) and a missing closing tag on one action card. The splash screen had an incorrect type attribute on the meta refresh tag that was flagged as a warning.

How they were resolved: The W3C validator highlighted the exact line numbers. Duplicate IDs were resolved by renaming the secondary element. The meta refresh type attribute was removed after confirming it is not a valid attribute for that element.

What I learned: Small structural errors in HTML — like a missing closing tag — can cause unexpected layout behaviour in some browsers without any obvious visual indication. Validation catches these invisible issues before submission.
